球と床のレイトレーシングによる画像生成

3次元空間に置かれた5個の球と市松模様の床を、指定した位置のカメラから見た画像として生成する。物体の色だけでなく、光による明暗、他の物体が作る影、鏡のような映り込みを計算する。

レイトレーシングは、カメラから画面の各画素を通る「光線」を飛ばし、どの物体に当たるか調べる画像生成手法である。本プログラムでは、光線が当たった場所の色を求め、それを画素の色として出力する。CGの画像生成を小規模なシーンで扱うことで、並列化と性能分析を学ぶ題材にする。 幅と高さはそれぞれ1〜16384、総画素数は1億以下、サンプル数は1〜1000000、反射回数は0〜16を受け付ける。
