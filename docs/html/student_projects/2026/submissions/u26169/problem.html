Making Atomic DFT from scratch

Problem

原子の密度汎関数理論（DFT）計算

How the algorithm/baseline code works

このコードは、He 原子（Z=2Z=2）に特化した球対称・全電子の最小 Kohn–Sham 計算です。 実装は「できるだけ短いこと」を優先し、標準 C++ ライブラリのみで動作します。

  • 系: He 原子（電子数 2、非スピン分極、1s 軌道のみ）

  • 離散化: 動径方向を有限差分（2次精度）

  • ポテンシャル:
    核ポテンシャル (Vnuc(r)=−2/rV_{\mathrm{nuc}}(r)=-2/r)
    Hartree ポテンシャル VH(r)V_H(r)（球対称密度から計算)
    LDA 交換ポテンシャル（簡略式）

  • SCF:
    初期波動関数 u(r)u(r) を与える
    密度 ρ(r)\rho(r) を作る
    Veff=Vnuc+VH+VxV_{\mathrm{eff}}=V_{\mathrm{nuc}}+V_H+V_x を更新
    固定ポテンシャル下で虚時間発展により 1s 軌道を更新
    密度の線形混合で安定化し、収束まで反復

  • 出力: he_dft_min.csv（r,ρ,veff,vh,vxr, \rho, v_{eff}, v_h, v_x）

この最小版は「依存ライブラリなし」「構造が見えやすい」ことが利点です。一方で、相関項の簡略化・基底の簡略化により、精度は本格 DFT 実装より劣ります。

  • 既知の値との比較 (He)

既知の基準値（非相対論的、文献値） $ E_{}   $
he_dft_min.cpp（例: nr=300, rmax=20）で得た値 $ E_{} = -2.708852803   $
誤差 $ |E_{}-E_{}| = 0.194871574   $
相対誤差は約 6.76.7% です。
これは「He 専用の最小コード」で交換相関や解法をかなり簡略化しているためです。

Where is parallelism

He 専用最小 DFT コードでも、主な計算は配列ループなので並列化しやすいです。

  • Hartree ポテンシャル計算（for i の中で for j）
    各 i の計算は独立なので、外側ループを並列化できます。
    計算量は O(Nr2)O(N_r^2) で、この部分が最も重くなります。

  • 密度・交換ポテンシャル・有効ポテンシャルの更新
    各格子点 i で独立な点ごとの演算なので、データ並列（SIMD / GPU）向きです。

  • ハミルトニアン作用 H*u（三重対角の stencil）
    各点の更新は近傍参照のみで、1次元 stencil として並列化しやすいです。
    メモリアクセス効率（連続アクセス）も良いです。
    (stencil: 配列の点iを近傍i-1,i,i+1で更新する計算)

  • 内積・ノルム計算（Rayleigh 商、正規化）
    和の計算なので並列 reduction が使えます。

一方で、SCF 反復そのものは「前の反復の密度を次の反復で使う」ため逐次依存があります。
したがって、並列化の中心は「各 SCF ステップ内の格子ループと reduction」です。
